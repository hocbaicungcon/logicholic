Sum Combinations in Kakuro

For each run, list distinct digits that add up to its clue, then use crossing runs to remove impossible combinations.

How it works

For each run, list distinct digits that add up to its clue, then use crossing runs to remove impossible combinations.

Example

A two-cell run summing to 3 must contain 1 and 2 in some order. A crossing clue decides which cell gets which digit.
