Number Clues in Minesweeper

Each number counts mines in its neighboring squares. Compare that count with confirmed flags and unknown squares.

How it works

Each number counts mines in its neighboring squares. Compare that count with confirmed flags and unknown squares.

Example

If a 2 touches exactly two unknown squares and no confirmed mines, both unknown squares are mines.
