Pointing Pairs and Triples in Sudoku

If every candidate for a digit in a box lies on one row or column, that digit cannot appear elsewhere on that line.

2026-10-042 min read
🎮 Play Sudoku →

How it works

If every candidate for a digit in a box lies on one row or column, that digit cannot appear elsewhere on that line.

Example

If every 6 in a box lies in its middle row, remove 6 from the rest of that row outside the box.

Key point

If every candidate for a digit in a box lies on one row or column, that digit cannot appear elsewhere on that line.
